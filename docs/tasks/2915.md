Это необязательное продолжение задачи «Магический квадрат». Отправьте отдельную полную программу, которая не только проверяет квадрат, но и находит первое расхождение.

Квадрат магический, если суммы всех строк, всех столбцов и обеих диагоналей одинаковы. Числа могут повторяться.

**Ввод:** сначала размер `n`, затем `n` строк по `n` целых чисел через пробел. `1 ≤ n ≤ 100`, значения — от `0` до `10000` включительно.

**Вывод:** если квадрат магический, напечатайте `YES`. Иначе напечатайте одну строку:

```text
NO: row K (sum S, expected E)
```

Здесь `E` — сумма первой строки, `S` — найденная отличающаяся сумма. Вместо `row K` используйте `col K` для столбца, `diag 1` для главной диагонали или `diag 2` для побочной. Строки и столбцы нумеруются с `1`.

**Порядок проверки:** строки сверху вниз, затем столбцы слева направо, затем главная диагональ, затем побочная. Сообщите только первое расхождение в этом порядке. Эталон во всех проверках — сумма первой строки.

**Примеры:**

| Ввод | Вывод |
|------|-------|
| `3`<br>`2 7 6`<br>`9 5 1`<br>`4 3 8` | `YES` |
| `3`<br>`2 9 6`<br>`7 5 1`<br>`4 3 8` | `NO: row 2 (sum 13, expected 17)` |
| `2`<br>`1 2`<br>`0 3` | `NO: col 1 (sum 1, expected 3)` |
| `2`<br>`1 2`<br>`2 1` | `NO: diag 1 (sum 2, expected 3)` |
| `3`<br>`0 0 1`<br>`0 1 0`<br>`1 0 0` | `NO: diag 2 (sum 3, expected 1)` |
| `1`<br>`7` | `YES` |

**Оценивание: 5 дополнительных баллов** — верный ответ для магических квадратов и верное первое расхождение для остальных: его вид, номер, фактическая и ожидаемая суммы. Ответа только `NO` недостаточно. Отдельных баллов за часть проверок нет.

**Проверка:** автотесты. Для полного зачёта нужно пройти все проверки. Эти баллы начисляются за отдельную задачу со звёздочкой, независимо от сдачи обычной задачи.
