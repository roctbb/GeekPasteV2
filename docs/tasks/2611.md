Квадратная матрица называется магическим квадратом, если суммы во всех строках, во всех столбцах и на обеих диагоналях одинаковы. Числа могут повторяться: проверять их уникальность не нужно.

**Ввод:** сначала размер `n`, затем `n` строк по `n` целых чисел. Числа в строке разделяются пробелами. `1 ≤ n ≤ 100`, значения — от `0` до `10000` включительно.

**Вывод:** одно слово `YES`, если квадрат магический, иначе `NO`. Указывать место расхождения в этой задаче не нужно.

Для удобства можно вынести подсчёт сумм строк, столбцов и диагоналей в функции. Автотесты проверяют результат программы.

**Примеры:**

| Ввод | Вывод |
|------|-------|
| `3`<br>`2 7 6`<br>`9 5 1`<br>`4 3 8` | `YES` |
| `3`<br>`2 9 6`<br>`7 5 1`<br>`4 3 8` | `NO` |
| `2`<br>`1 2`<br>`2 1` | `NO` |
| `1`<br>`7` | `YES` |

**Оценивание: 5 баллов** — программа правильно определяет, магический ли квадрат, учитывая все строки, все столбцы и обе диагонали. Отдельных баллов за часть проверок нет.

**Проверка:** автотесты. Для полного зачёта нужно пройти все проверки.

В третьем примере суммы строк и столбцов равны `3`, но сумма главной диагонали равна `2`, поэтому ответ — `NO`.
