# Оценки внешнего API

`external_check_task` возвращает результат проверки без балла за сдачу:
0 остаётся 0, положительная оценка не повышается, комментарий не дополняется
сообщением о балле за попытку. Это относится и к `gpt`, и к `tests`.
При ошибке проверки сохраняются `status: error` и 0 баллов.
Ограничение нейросетевой оценки максимумом задания сохраняется.
Правило минимального балла для обычных сдач внутри GeekPaste не меняется.

Для `check_type: gpt` параметр `check_config.assessment_mode` выбирает промпт:

- `code` (по умолчанию) — прежняя проверка законченной программы.
- `rubric` — учебный ответ по независимым критериям преподавателя, включая
  код вместе с пояснением и исправленные фрагменты программы из условия.

GeekExam передаёт `rubric` по умолчанию для своих AI-заданий; в конфигурации
конкретного задания можно явно выбрать `code`. `max_points`, `answer` и
`prompt` продолжают задавать максимум, эталон и критерии. Формат callback
не меняется.

Промпт режима `rubric` находится в `grading_prompts.py`. Критерии, условие
и эталон передаются в системном сообщении; ответ ученика — отдельным JSON
в пользовательском сообщении. Правильное объяснение обычным текстом перед
кодом не считается синтаксической ошибкой, а ошибка в одном критерии не
обнуляет независимые выполненные критерии.

Это разделение следует [рекомендациям OpenAI по ролям и структуре промптов](https://developers.openai.com/api/docs/guides/prompt-engineering).

Регрессионные проверки:

```sh
python -m unittest discover -s tests -p 'test_api_grading.py' -v
python -m unittest discover -s tests -p 'test_submission_minimum_chain.py' -v
```

Изменение применяется к новым проверкам и ручным перепроверкам; уже выставленные
оценки не пересчитываются автоматически.
