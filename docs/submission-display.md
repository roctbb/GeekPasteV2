# Отображение авторов решений

GeekPaste сохраняет `name` из проверенного JWT GeekClass в таблицу
`user_profiles`. Если имени ещё нет, GeekPaste получает его через одиночный
`GET /api/geekpaste/users/{id}` на CodingProjects. В ответе — только `id` и
`name`. Поэтому имена появляются и у старых решений без повторного входа
учеников. Полученное имя кешируется для всех решений пользователя; следующий
вход с JWT обновляет его.

При развёртывании нужно применить миграцию: `flask --app manage db upgrade`.
Также нужно выложить метод получения пользователя в CodingProjects.
Используются существующие `SUBMIT_URL` и `JWT_SECRET`. Каждый запрос содержит
в `Authorization: Bearer` JWT на 60 секунд с `purpose=user-profile`,
`aud=codingprojects` и запрашиваемым `user_id`.

Если пользователя нет или сервис недоступен, интерфейс показывает
«Пользователь #ID». После ошибки обращения к сервису приостанавливаются на
минуту. Ссылка ведёт в профиль GeekClass; ID также доступен во всплывающей
подсказке.

Для Markdown в `.ipynb` сборка `npm run build:vendor` копирует локальные
Marked и DOMPurify. Они загружаются перед Notebook.js на странице тетрадки,
чтобы форматировать Markdown и очищать HTML ячеек и результатов выполнения.
